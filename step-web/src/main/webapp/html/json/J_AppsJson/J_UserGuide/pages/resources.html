The Manuscripts and Meanings Feature

All bible translations represent decisions about what the original text said (based on manuscripts) and what the original text was intended to convey in the original culture (the meaning). This chapter discusses some of the issues and considerations around this reality, STEPBible's response to those possibilities and implications of this reality, a not-yet-available STEPBible feature, which promises great usefulness when completed.
